IBM's extraction text survived the migration: 'IBM is listed in the org directory.'
But its SOURCE-node link did not: source=None, source_original=None
Gotcha: export_database_data/import_database_data carry over extraction *text*
(re-linked via a fresh EXTRACTED_FROM edge on import) but SOURCE nodes themselves
are never exported -- only entities/facts/property values are. If you need the
SOURCE name/original date to survive a migration too, add_source() them again in
the target database and re-link with add_*_extraction(..., source_id=...).
